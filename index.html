Privacy & Data Handling

This application is a client-side utility hosted on GitHub Pages. All PDF processing occurs locally within your browser session. Uploaded schedule files are not transmitted, stored, logged, or retained by any server or third party.

Once parsing is complete, the file exists only in your browser’s temporary memory and is discarded when the page is refreshed or closed.
